# Fedi3 Name and Trademark Policy

The name **Fedi3** identifies the protocol and the reference implementation
maintained in this repository. It is not a registered trademark, but it is used
consistently to avoid confusing users.

## Rules

- **Forks and derivatives must use a distinct name and logo.** A fork may say
  "based on Fedi3" or "Fedi3-compatible" when that is accurate.
- **Do not imply official endorsement.** Only the reference implementation and
  releases published from this repository are official.
- **Describe compatibility honestly.** "Fedi3-compatible" means the software
  speaks the documented protocol and federates correctly; it does not mean the
  fork is maintained by the Fedi3 maintainer.
- **Do not misrepresent the origin of the code.** Keep the AGPL license,
  copyright notices and a clear statement of changes.
- **Protocol references are allowed.** Documentation and relay directories may
  refer to "Fedi3" when describing the protocol, the relay contract or the
  shared directory.

## Scope

This policy governs naming and presentation only. It does not limit the rights
granted by AGPL-3.0-or-later: you may reuse, modify and redistribute the code
freely, provided you follow the license and do not mislead users about what they
are running.

Questions about a name or logo can be raised in a GitHub issue or by contacting
the maintainer [@redhunt07](https://github.com/redhunt07).
