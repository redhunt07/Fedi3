# Fedi3 v0.12.5

## Italiano

Questa versione ripristina la cronologia dei profili e corregge il recupero dei
contenuti e dei media tra client, P2P e relay.

- Post, risposte e media dei profili vengono uniti alla cronologia persistente
  completa; follow e reazioni non possono più rendere vuota la prima pagina
  dell'outbox pubblico.
- Scopri esclude anche i follow in attesa e aggiorna i suggerimenti. Le pagine
  vuote mantengono il caricamento degli elementi precedenti.
- Cerca/Tutti mostra i risultati disponibili durante la sincronizzazione
  dell'indice relay, evitando l'errore 503 di copertura incompleta.
- La cache media rispetta il nome del file persistito, anche dopo ripristino.
- Il P2P può usare WebSocket con TLS sulla porta HTTPS 443 quando TCP/QUIC 4001
  è filtrato. Il contesto Android viene inizializzato prima del core, mantenendo
  disponibili DNS di sistema e verifica dei certificati.
- La ricompilazione desktop sostituisce atomicamente la libreria del core,
  preservando quella già caricata dai processi aperti.

Aggiornare relay e infrastruttura prima dei client. Abilitare
`FEDI3_P2P_INFRA_WSS_ENABLE=true` soltanto quando il proxy TLS inoltra
`/_fedi3/p2p` al listener WebSocket interno `p2p_infra:4002`. Caddy è già
configurato; con un proxy esterno occorre aggiungere lo stesso inoltro.
Conservare dati, identità e portachiavi: non ricreare il profilo.

Pacchetti: AppImage Linux x86_64, DEB amd64, ZIP Windows x64, APK Android
arm64-v8a e x86_64, con `checksums.txt`. Codici Android: 8022 (arm64),
10022 (x86_64). Gli aggiornamenti mantengono la firma del canale esistente.

## English

This release restores profile history and corrects content and media retrieval
across the local client, P2P and relay.

- Profile posts, replies and media merge with complete persisted history;
  relationship activities no longer consume the first public outbox page.
- Discover excludes pending follows and refreshes suggestions. Empty pages
  retain access to older content.
- Combined search returns available results while relay indexing catches up,
  avoiding the incomplete-coverage 503 in interactive search.
- Media caching respects persisted filenames, including restored uploads.
- P2P supports TLS WebSocket circuits on HTTPS port 443 when raw TCP/QUIC 4001
  is filtered. Android initializes its application context before the core so
  system DNS and certificate verification remain available.
- Desktop rebuilds atomically replace the core library without truncating a
  library already mapped by a running client.

Upgrade the relay and infrastructure before clients. Enable
`FEDI3_P2P_INFRA_WSS_ENABLE=true` only when the TLS proxy forwards
`/_fedi3/p2p` to the internal `p2p_infra:4002` WebSocket listener. The bundled
Caddy configuration does this; external TLS proxies need the equivalent rule.
Retain identity, data and keyring rather than recreating the profile.

Packages: Linux x86_64 AppImage, amd64 DEB, Windows x64 ZIP, Android arm64-v8a
and x86_64 APKs, plus `checksums.txt`. Android version codes: 8022 (arm64),
10022 (x86_64). Updates retain the existing channel signing identity.
